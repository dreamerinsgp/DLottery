## 等待时间与不同结果

钱包确认和 VRF 等待可能超过视频时长。可以先录完整过程，再剪去等待时间，并明确标注“等待交易确认/VRF”。不要把待处理请求表现为完成结果，也不要把本地模拟随机数当成公网 VRF。

如果截止前不足五人，不应修改合约或暗示两人就能提前开奖。改为展示已完成的历史记录和交易证据。如果当前轮次已满或结束，先展示结果或历史，待新轮次允许参与后再录制购票。

若真实结果有人中奖，展示 **Claim your prize** 和确认回执；若无人中奖，展示滚存；若演示取消，只有在到期且执行结算后，才展示参与者退款。不要声称最初的公网演示覆盖了领奖和退款，这些分支是在本地验证的。

可选的确定性分支演示使用 `npm run demo`、`npm run demo:fill`、`npm run demo:draw -- 1` 或 `-- 10`，并清晰标注为**本地链 31337，使用模拟随机数**。本地辅助工具会拒绝公网链。

## 交付方式

导出清晰可读的 MP4 或可访问的视频链接。确保网址、网络、交易确认和证据文字清楚，并测试分享权限。录制完成后，将真实视频链接加入[提交说明](submission-template.zh-CN.md)；在成品产生前不要提供虚构的视频地址。
